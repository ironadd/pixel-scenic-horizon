# 山海晴岚 · 像素风景线 (Voxel Scenic Horizon)

基于 **Three.js + 程序化 16×16 像素艺术纹理图集 + 4-Tap 体素顶点环境光遮蔽 (Vertex AO) + 像素网格量化海浪与天穹着色器 + UnrealBloom 辉光后处理** 构建的 **68.7 万+ 方块**立体像素山海风景线。

- **在线预览 (GitHub Pages)**：https://ironadd.github.io/pixel-scenic-horizon/

## 风景构图与亮点

- **山海立体长卷构图**：远景北境皑皑雪峰与松林云海 → 中景三叠翡翠飞瀑（晴日折射像素彩虹）、水车磨坊村落、朱红溪谷拱桥、阳光层叠梯田与秋色银杏枫林 → 前景月牙黄金沙滩、观海木栈道、海上鸟居礁石与白帆小船。
- **跨海石拱铁道与「山海号」复古列车**：六孔罗马砂岩石拱铁道桥横跨河口与碧海浅湾，复古绿白配色观光列车喷吐体素蒸汽缓行过站、穿越山体隧道，海滨平交道口红白栏杆与警示灯随列车自动起落闪烁。
- **东岬红白望海灯塔与西岭花田风车**：白垩断崖之巅伫立红白条纹像素灯塔（黄昏与夜晚扫射体积光束并在海面投下波光），西侧繁花山坡转动荷兰风车，铺满薰衣草、郁金香、向日葵与虞美人花带。
- **四时晴岚与 24 小时昼夜流转**：
  - `🌸 春樱朝雾`：柔粉晨曦、飘落樱花瓣与山谷轻雾
  - `☀️ 碧海晴岚`：通透琉璃浅海、飞瀑彩虹与白浪拍岸
  - `🌇 橘海落日`：巨型像素夕阳沉入海平线，铺开碎金海面反光
  - `🌌 星海渔火`：璀璨星河与北境极光、灯塔扫海、林间萤火虫与海岸荧光“蓝眼泪”浪花
- **多重视角与像素画风切换**：支持 `🖼️ 全景长卷`、`🚂 搭乘列车`、`⛵ 碧海巡航`、`🦅 自由飞行 (WASD)` 四种视角；一键切换 `精致体素 / 细腻像素画 / 复古像素风` 三种像素渲染质感；内置纯 Web Audio 海浪与治愈五声轻音乐合成器。

## 启动方式

双击根目录下的 `启动像素风景线.bat`，或在终端执行：

```bash
npm install
npm run dev
```
